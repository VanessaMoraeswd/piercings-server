# piercings-server

A minimal and highly efficient RESTful API built with native Node.js. 

## 🧩 Features

- **Vanilla Node.js Implementation:** Zero third-party dependencies for maximum performance and deep understanding of the core HTTP module.

- **Event-Driven Request Parsing:** Handles incoming JSON payloads efficiently using Node.js streams (`data` and `end` events).

- **Architecture:** Organized using the Controller pattern for clean separation of concerns.

## 🛠️ Tech Stack
- Node.js (Native Modules)
- JavaScript (ES6+)
